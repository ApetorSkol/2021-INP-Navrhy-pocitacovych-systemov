# 2021 INP Navrhy pocitacovych systemov
Pocas semestra sme robili dva projekty. Prvy bol vytvorenie procesoru v jazyku VHDL. Procesor mal byt schopny robit bezne operacie ktore ma procesor zvladat.
Druhy projekt bol zasifrovanie naseho loginu (v mojom pripade xslivk03) pomocou vernamovej sifry. Druhy projekt bol pisany v assemblery.
